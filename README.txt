BIRTHDAY GIFT — SIAP UPLOAD

Website ini sudah berisi foto, musik, tanggal ulang tahun 23 Agustus 2026, dan ucapan romantis.

CARA UPLOAD KE GITHUB PAGES:
1. Buat repository GitHub baru (misalnya: birthday-gift).
2. Upload SEMUA isi folder ini, bukan file ZIP-nya.
3. Pastikan index.html berada di folder utama repository.
4. GitHub: Settings > Pages > Deploy from a branch > pilih main > / (root) > Save.
5. Tunggu beberapa saat, lalu buka link GitHub Pages yang diberikan GitHub.

CATATAN:
- Jangan memindahkan music.mp3 dari folder utama.
- Jangan memindahkan folder images.
- Foto yang dipakai adalah foto asli yang kamu upload.
